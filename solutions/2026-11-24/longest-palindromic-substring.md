# Longest Palindromic Substring

🟡 **Medium** &nbsp;·&nbsp; Date: 2026-11-24 &nbsp;·&nbsp; Attempts: 1 &nbsp;·&nbsp; [View on LeetCode](https://leetcode.com/problems/longest-palindromic-substring/)

---

Given a string s, return the longest palindromic substring in s.

&nbsp;
Example 1:

Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.

Example 2:

Input: s = "cbbd"
Output: "bb"

&nbsp;
Constraints:

	1 <= s.length <= 1000
	s consist of only digits and English letters.
