# Binary Tree Paths

🟢 **Easy** &nbsp;·&nbsp; Date: 2026-09-23 &nbsp;·&nbsp; Attempts: 1 &nbsp;·&nbsp; [View on LeetCode](https://leetcode.com/problems/binary-tree-paths/)

---

You are given the root of a binary tree.

Return all root-to-leaf paths in any order.

A leaf is a node with no children.

&nbsp;
Example 1:

Input: root = [1,2,3,null,5]
Output: ["1->2->5","1->3"]

Example 2:

Input: root = [1]
Output: ["1"]

&nbsp;
Constraints:

	The number of nodes in the tree is in the range [1, 100].
	-100 <= Node.val <= 100
