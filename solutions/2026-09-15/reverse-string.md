# Reverse String

🟢 **Easy** &nbsp;·&nbsp; Date: 2026-09-15 &nbsp;·&nbsp; Attempts: 1 &nbsp;·&nbsp; [View on LeetCode](https://leetcode.com/problems/reverse-string/)

---

Write a function that reverses a string. The input string is given as an array of characters s.

You must do this by modifying the input array in-place with O(1) extra memory.

&nbsp;
Example 1:
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
Example 2:
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]

&nbsp;
Constraints:

	1 <= s.length <= 105
	s[i] is a printable ascii character.
